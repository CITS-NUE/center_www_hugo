メールサービスに Microsoft 365 Exchange Online を採用しています。本学ドメインのメールアドレスをご利用いただけるほか，ブラウザから Outlook Web アプリ (Outlook on the web) にアクセスしてメールの送受信を行えます。

## アカウント（ユーザ名）／パスワードとメールアドレス
### 認証アカウント（ユーザ名）／パスワード
Microsoft 365 のアカウント（ユーザID@naruto-u.ac.jp）で認証します。入学時に発行する「ユーザID通知書」に記載されています。
### メールアドレス
本学ドメイン（@naruto-u.ac.jp）のメールアドレスです。入学時に発行する「ユーザID通知書」に記載されています。
### 利用期間
在学中，利用できます。卒業，修了，退職後は，メールアドレスを利用できません。必要なデータは移行してください。
### 多要素認証（MFA）の設定
学外ネットワークからアクセスする場合は，多要素認証の対象となるため，利用時に入力を求められることがあります。設定については，[こちら]({{< ref "mfa" >}}) をご覧ください。

(For foreign users, please refer to [the manual in English]({{< ref "20220817" >}}).)
### エイリアス（別名）
学生は別名（エイリアス）を設定できます。→ [こちら]({{< ref "mail#メールエイリアス別名の登録" >}})
教職員は別名（エイリアス）を追加できます。→ [こちら]({{< ref "mail#メールエイリアス別名の追加" >}})
### 送受信の制限
(2026年5月時点)

Exchange Online の制限により，メールの送信・受信が一時的に制限される場合があります。

**受信に関する制限**
- 1 時間あたり 3,600 通を超える受信メール → 一時的に外部からのメール受信が停止します。
- 特定の送信者から短時間に大量のメールを受信した場合 → その送信者からのメールのみ受信が停止します。
- 1 時間あたり 1,000 通を超える受信が継続する場合 → 危険状態として記録されます（受信は停止しません）。

**送信に関する制限**
- 1 日あたり 10,000 を超える受信者への送信
- 1 通あたり 500 を超える受信者数への送信
- SMTP クライアント送信（SMTP AUTH）での大量送信 → レガシー方式のため，大量送信には適しません。

## Webメール：Outlook Web アプリの使い方
Webブラウザから，Microsoft 365 アカウントでサインインして利用します。

1. Webブラウザを起動し，サインインページへアクセスします。

   **URL**: https://outlook.office.com/（または https://portal.office.com → Outlookアプリ を選択）

   > Webブラウザは，最新版をご利用ください。
2. サインインします。

   サインインには，Microsoft 365アカウント（ユーザID@naruto-u.ac.jp）を使用します。

   > サインインに使用するのは Microsoft 365 アカウント（ユーザID@naruto-u.ac.jp）であり，エイリアスなどのメールアドレスではありません。
   > 初回起動時のみタイムゾーン設定画面が表示されますので，「大阪，札幌，東京」(Osaka, Sapporo, Tokyo) を選んでください。
3. 多要素認証（MFA）を求められる場合には，入力します。

## メールソフトの設定
メールソフトが，Exchangeプロトコル または 先進認証（OAuth2.0）に対応していることをご確認ください。Microsoft365の，IMAPプロトコルによる認証は2022年10月1日に廃止されました。多要素認証の対象ですので，メールソフトのアプリケーションパスワードは使用できません。

Exchangeプロトコルが利用できるメールソフト
- Outlook（デスクトップアプリ）
- Macメール(OS X)
- iPhone標準メールアプリ
- Gmailアプリ（Android版）など

OAuth2.0認証に対応したメールソフト
- Mozilla Thunderbird 78.0 以降，など

> GmailのメールアプリはOAuth2.0に対応していません。

### Exchangeプロトコルで設定する
ほとんどの場合，メールアドレスおよびユーザ名（ユーザID）とパスワードを入力するだけで自動的にサーバを検索し，設定を完了します。また，メールソフトのメール/予定表/連絡先をOutlookと同期して利用できます。

**設定例**
- [Microsoft Outlook 2016](exchange-outlook2016.pdf)
- [Macメール(OS X バージョン10)](exchange-mac-mail10-new.pdf)
- [iPhone 標準メールアプリ（iOS 12.2）](iPhone-exchange.pdf)
- [Gmailアプリ Android (8.0)](GmailAndroid.pdf)

### OAuth2.0 認証で設定する
**設定情報**

| 設定項目 | 受信サーバー | 送信サーバー |
| --- | --- | --- |
| プロトコル | IMAP | SMTP |
| サーバー | outlook.office365.com | smtp.office365.com |
| ポート番号 | 993 | 587 |
| SSL | SSL/TLS | STARTTLS |
| 認証方式 | 通常のパスワード認証 ⇒ OAuth2 | 通常のパスワード認証 ⇒ OAuth2 |
| ユーザー名 | ユーザID@naruto-u.ac.jp | ユーザID@naruto-u.ac.jp |
| ユーザーID | ユーザID（学籍番号・教職員番号）※メールアドレスではありません |  |

## 関連サービス（学生）
### メールエイリアス（別名）の登録
メールエイリアス（別名）を登録できます。メールアドレス初期値（ユーザID@naruto-u.ac.jp）の，ユーザID（学籍番号）部分を変更したアドレスを，登録できます。登録できるのは **在学中に1回だけ** です。

[こちら](https://idm.naruto-u.ac.jp/mailweb/) から登録してください。

1. ユーザID（学籍番号）とパスワードを入力
2. メールアドレス (alias) の入力欄へ，登録を希望するメールアドレス（@より前の部分）を入力
3. [更新] ボタンで保存
4. ログアウト

> 次に該当するメールアドレスは使用できません。
> - 過去に登録されたメールアドレス
> - 他の人が使用しているメールアドレス
> - 本学の教育・研究・管理運営に支障のあるメールアドレス
> - 公序良俗を害する恐れのあるメールアドレス

※メールアドレス初期値（学籍番号@naruto-u.ac.jp）でも受信できます。
※ユーザID（学籍番号）や Microsoft365アカウント（学籍番号@naruto-u.ac.jp）は変わりません。
