## 学内共通
### ソフトウェアライセンス利用
以下のソフトウェアをインストールできます。

- 学生および教職員
  - Microsoft Defender Endpoint
  - yarai endpoint security
- 教職員
  - Microsoft Office デスクトップ版
  - Microsoft Windows アップグレード

[オンライン申請](https://forms.office.com/r/2xbjqYZkpD)

### プリンタ印刷利用ポイント追加
毎年付与される印刷ポイントが足りなくなったときに 1000ポイント/1000円の単位で追加購入できます。オンラインで申請し，財務課でお支払いください。お支払い後にポイントが追加されます。

[オンライン申請](https://forms.cloud.microsoft/r/MtWM8Ekx2t)

### 施設利用
端末室やデジタル出力室を予約して，講義・ゼミ・制作作業などに利用できます。

[オンライン申請](https://forms.office.com/r/zPdcbcB84a)

## 教職員専用

### 大判カラープリンタ利用
ポスターや看板の印刷にご利用ください。経費は，コース等の配分経費からの振替となります。経費振替の関係から，学生または学生団体が利用する場合も教員からの申請が必要です。

[申請書(PDF)](../../pdfs/printer_f.pdf)

### ユーザID
ユーザIDを追加したり，ゲスト用のIDを作成できます。メールアカウントの追加も可能です。

[オンライン申請](https://forms.office.com/r/D3NGLPVQAz)

### メーリングリスト
学内メールアドレスのリストや，学外のメールアドレスを含むリストを作成できます。

[オンライン申請](https://forms.office.com/r/kBr4yX9KDH)

### ネットワーク接続
共有プリンタや NAS に固定IPアドレスを配布できます。

[オンライン申請](https://forms.office.com/r/kQxFyj0NxS)

### ウェブページ公開
講座や個人のウェブページを公開できます。

[オンライン申請](https://forms.office.com/r/qG43XeQkq3)

### メールアドレス継続利用
教員は，大学を離れた後もメールを利用できます。

[オンライン申請](https://forms.office.com/r/L9j7sLVxXw)

### 学外からの接続利用
学外から学内のサーバやサービスが利用できるようになります。メンテナンス等で学外者へ依頼する場合は，担当教職員が申請してください。

[オンライン申請](https://forms.office.com/r/jfA428Fns5)

### DNS の A レコード登録
Domain Name System サーバへの A レコードの登録申請です。「naruto-u.ac.jp」ドメインの A レコードに登録します。

[オンライン申請](https://forms.office.com/r/UVP7XUG7Ar)

### ドメイン参加申請
共用端末を大学ドメインに参加させたり，脱退させたりできます。Windows Home Edition は，ドメイン参加に対応していません。Windows Pro へのアップデートが必要です。

[Windows バージョン確認方法](https://pc-karuma.net/windows-10-edition/)
[オンライン申請](https://forms.office.com/r/VjCL3S9Rum)
