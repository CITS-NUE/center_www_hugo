本学がライセンス契約を結んでいるソフトウェアを，端末室や研究室，または個人の端末で利用することができます。  
 契約の形態はソフトウェアごとに異なっていますので，それぞれのソフトウェアについての利用案内をご覧ください。  
 また，契約の更新に伴い，利用要項は変更されることがあります。
 

## インストールできるソフトウェア
 本学が包括的にライセンス契約を結んでいるソフトウェアは，研究室や個人の端末へインストールして利用できます。
 
 本学の教職員や学生の利用を対象としたライセンス契約です。    
 本学が契約を結んでいる期間中，その契約内容に従って，利用できます。    
 契約更新とともに，利用手引きも変更されますので，ご了承ください。   
 本学がライセンス契約を解除したときや，利用者が利用対象外となったときには，利用できなくなります。  
 
### Office365 （Microsoft 365）アプリ版
教職員，学生は，Office365アプリ をインストールできます。    
申請の必要はありません。  
> 個人で購入したパソコン等にもインストールできます。  
> 卒業・修了／退学・退職時には利用する権利がなくなります。  
 
#### インストール手順
> Microsoft社の"Office 365 Education"サイトからのはインストールできません。  
1. [Microsoft 365 サイト](https://login.microsoftonline.com)へ，本学 Microsoft アカウント（ユーザID@naruto-u.ac.jp）でサインイン
1. 左側メニューからアプリ画面を開く
1. 上部の [アプリをインストール] ボタンを押下
1. Microsoft 365 Apps を選択
1. Officeのインストールボタンから，ダウンロードしてインストール  
 
#### インストール台数
 ・Windows PCまたはMacintosh  
 　1ユーザあたり5台まで  
 ・タブレット（iPad, Android, Windowsタブレット）  
 　1ユーザあたり5台まで  
 ・スマートフォン（iPhone, Android）  
 　1ユーザあたり5台まで  
 　   
#### 院生室など共有のPCの場合は・・・
 下記 [Microsfot Office デスクトップ版](#office-desktop) をご利用ください。  
 院生室・研究室など，複数人で共有して使用する端末の場合，学生・教員のアカウントを使ってインストールすると，アカウント情報のセキュリティが守られません。
 
 
### Microsoft Office デスクトップ版 {#office-desktop}
教職員が管理する共有の端末に，Microsoft Office デスクトップ版 をインストールできます。(アプリ単位での追加は出来ません)  
個人のPCには上記 Microsoft 365 アプリ版をご利用ください。  
Windows OS または，Mac OS のライセンスが必要です。    
[ソフトウェア利用申請 ](https://forms.office.com/r/2xbjqYZkpD)  
> インストールするPCの仕様が要件を満たしているかどうかご確認ください。   
> インストール手順は，申請承認後に自動メール送信します。  
> 学内ライセンスサーバによる認証です。6カ月に1度は，学内ネットワークへ接続して認証してください。  
> Windows Sモード の場合は，Windows Home または Proに切り替え（解除）してください。    
> 退職時には，アンインストールしてください。  
 
 
### Microsoft Windows アップグレード
教職員および学生は，管理する端末の Microsoft Windowsをアップグレードできます。  
Windows OS のライセンスが必要です。（新規インストールはできません）  
[ソフトウェア利用申請 ](https://forms.office.com/r/2xbjqYZkpD)  
> アップグレードするパソコンの仕様が各OSの要件を満たしているかどうかご確認ください。   
> アップグレード手順は，申請承認後に自動メール送信します。
> 学内ライセンスサーバによる認証です。6カ月に1度は，学内ネットワークへ接続して認証してください。
> 退職時には，元のバージョンに戻してください。
   
### Microsoft Defender for Endpoint
教職員および学生は，管理する端末に，Microsoft Defender for Endpoint をインストールできます。  
Defender for Endpoint をインストールした端末は，情報基盤センターが管理ポータルで脅威を確認できるようになります。  
Windows および MacOS へインストールできます。  
[ソフトウェア利用申請 ](https://forms.office.com/r/2xbjqYZkpD)  
> インストール手順は，申請承認後に自動メール送信します。
